# Changelog

## 0.8.2

- New icon: three gauge rows (context, cache, plan usage) instead of two, so the fork is easy to tell apart from the original. Generated by `scripts/make_icon.ps1` (no Python needed).
- README: real screenshots of the status bar item, the compact reminder and the tooltip.
- Release workflow: current major versions of all actions, builds on Node 24.

## 0.8.1

- First release on the VS Code Marketplace and Open VSX. Marketplace publishing signs in with Microsoft Entra ID (no stored token).
- README: install/update instructions, commands, and the configurable reminder text.

## 0.8.0

- New setting `vscodeClaudeTokenUsageBarExt.compactNudge.message` for the text the compact reminder flashes (supports `$(icon)` names).
- Removed the Korean README (`README.ko.md`), which still described the original extension.

## 0.7.0 (renamed: Claude Token Usage Bar Ext)

- Renamed everything after the repository, `vscode-claude-token-usage-bar-ext`: extension ID `kaedinger.vscode-claude-token-usage-bar-ext`, display name "Claude Token Usage Bar Ext".
- Settings and commands renamed from `claudeMonitor.*` to `vscodeClaudeTokenUsageBarExt.*`, so the fork no longer collides with the original extension. Existing `claudeMonitor.*` settings need to be re-entered under the new names.

## 0.6.0 (fork: Claude Usage Bar Plus)

- New segments: estimated prompt cache state (`cache 37m` / `cache cold`) and 5-hour / 7-day plan usage from Claude Code's saved reading, with an optional, off-by-default API fallback.
- "Compact before closing" nudge: flashes periodically while the context is large and the cache is warm.
- Fixed workspace matching on Windows (drive-letter case) and for multi-root workspaces; long project paths match on the truncated prefix.
- Respects `CLAUDE_CONFIG_DIR`.
- Fixed totals counting each response 2–3×: Claude Code writes one line per content block with the same usage, so messages are now deduplicated by id. Sync-conflict copies of transcripts are ignored.
- Context ignores subagent (sidechain) and `<synthetic>` records, and shows `Ctx compacted` after `/compact` until the next response.
- Model table updated (Opus 5.5/5, Sonnet 5.5/5, Haiku 5.5, Fable 5.1 = 1M; 4.5 models = 200k). Unknown models fall back to the setting and say so in the tooltip.
- Logs are read incrementally (only appended bytes) instead of re-reading whole files every refresh.
- Per-segment show/hide settings; "Today" is now off by default.

## 0.5.1

- Hover dashboard now visualizes **every project's** total token usage as a bar chart (no longer capped at 6), sorted by usage. Per-file caching keeps it fast.

## 0.5.0

- **Hover dashboard.** The tooltip is now a mini dashboard: current session context (used / remaining / model, auto-detected window) plus today's tokens broken down **per project** with mini bars.

## 0.4.2

- Cleaner status bar: removed the `$(thinking)` / `$(graph)` icons and switched the gauge to segmented `▰▱` pills (filled segments render in the theme's foreground — light/white on dark themes), with a `·` separator between the context and today parts.

## 0.4.1

- Added a screenshot to the README and trimmed it to user-facing content.
- Renamed the command and settings labels to "Claude Token Usage Bar" to match the extension.

## 0.4.0

- **Fixed the context bar reading 100% on 1M-context models.** The window size is now auto-detected from the session's model (Opus 4.8/4.7/4.6/4.5, Sonnet 5/4.6/4.5, Fable/Mythos 5 = 1M; Haiku 4.5 = 200k) instead of assuming 200k. New setting `claudeMonitor.autoDetectContextWindow` (default on); `claudeMonitor.contextWindow` default raised to 1,000,000 and is now the fallback when the model is unknown. The tooltip shows the model and whether the window was auto-detected.

## 0.3.1

- Fixed `repository`/`bugs`/`homepage` URLs to the actual GitHub repo, and made README links absolute, so links on the Marketplace page no longer 404.

## 0.3.0

- Added the extension icon.
- Marketplace release of the current feature set (current-session scope, single status bar item, % used, today's usage).

## 0.2.0

- **Current-session aware:** the context bar now tracks the newest session of the *currently open workspace's* project instead of the globally newest log. New setting `claudeMonitor.scope` (`workspace` default, or `global`).
- **Single status bar item:** context and today's usage are merged into one item, so other status bar entries (Copilot, encoding, Ln/Col…) can no longer wedge between them.
- Context now shows **% used** instead of % left.
- Added a bundled `.vscode/launch.json` so pressing **F5** launches the Extension Development Host directly (no debugger picker).

## 0.1.0

- Added a second status bar item showing **today's cumulative token usage** (input + output + cache, summed across all sessions for the local day).
- New setting `claudeMonitor.showTodayUsage` to toggle it.

## 0.0.1

- Initial release.
- Live context-window usage bar in the status bar.
- Warning/error background colors at 25% / 10% remaining.
- Configurable context-window size, refresh interval, bar width, and alignment.
